# Corporate OPEX Budgeting & Forecasting

A driver-based operating-expense budgeting and forecasting project built in Advanced Excel.

## Overview
- Compared historical departmental expenses across **payroll, technology, facilities, travel and vendor costs** to identify spending patterns and establish budget drivers for annual financial planning.
- Engineered an **Advanced Excel financial model** linking headcount, vendor contracts, planned spending and historical expense trends to develop **annual OPEX budgets and monthly forecasts**.

## Skills & Tools
Advanced Excel · OPEX Budgeting · Driver-Based Planning · Forecasting · Expense Trend Analysis
